# J-Split 日文意群助读与划词翻译

> ⚠️ **特定适用范围提示 (Notice)**：  
> **本项目脚本/扩展专为「小説家になろう」日文轻小说网站量身打造，只能特定用在：**  
> 🔗 **`https://syosetu.com/?ref=ncodeheader`** （及 `*.syosetu.com` 作品正文页面）。  
> 针对该站的正文容器与小说排版结构进行了专门的 DOM 锚定、原文字距零膨胀断句优化。

---

专为在 Safari / Chrome / Edge 上沉浸式阅读《小説家になろう》生肉小说打造的 **AI 意群助读与无感翻译助手**。

解决传统翻译打断心流、破坏版面的痛点：**零排版膨胀、纯靠断点虚线自然界定意群、点击瞬间弹出 macOS Dock 级高透毛玻璃气泡、结合整句故事语境精准翻译、底部小字平假名注音**。

---

## 🌟 核心特性

- 🌸 **无感意群断句（零排版膨胀）**：
  - 点击右下角 `[ 🌸 意群助读 ]` 或按快捷键 `Alt + S`，正文自动按意群加上优雅的粉色小虚线；
  - **彻底舍弃多余的斜杠 `/` 与空白边距**，小说字间距、行高与原网页 100% 保持完全一致；
  - 再按一次 `Alt + S`，瞬间无损还原纯净原网页。
- 🔮 **macOS Dock 级高透毛玻璃气泡**：
  - 像素级复刻 macOS Dock 图标悬浮提示框；
  - **72% 超高透光度 + 3.5px 微磨砂**，气泡盖在文字上时，**背后的日文笔画骨架清清楚楚透视过来**，绝无任何死黑或实心水泥灰；
  - 纯白高清晰文字带柔和阴影，上下层互不干扰。
- 🧠 **整句上下文感知精准翻译（Context-Aware）**：
  - 点击单个短语（如 `抜けて、` 或 `時間に`），插件自动提取其所在的整句剧情语境一同发给大模型；
  - 告别生硬机械的单字直译，准确度完美契合小说情节！
- 📖 **纯平假名注音**：
  - 气泡顶部为地道中文释义，底部为该词对应的纯平假名读音（如 `みせない。`、`てんせいした。`），无痛认读汉字读音，零语法术语打扰。
- ⚡ **毫秒级极速响应 + 本地缓存**：
  - 极简 Prompt 设计，大模型仅需生成几个字，0.1 ~ 0.3 秒即时出结果；
  - 点过的短语自动存入内存缓存，再次点击 0 毫秒秒出。
- 🔄 **自动检索平台模型**：
  - 完美适配 **[词元跳动 (tokendance.space)](https://tokendance.space)** 及任意兼容 OpenAI 接口的服务商；
  - 输入 Base URL 和 API Key 后，点击「🔄 自动检索模型」即可下拉点选，无需手动打字（推荐 `qwen3.8-flash` 极速模型）。

## 🍎 Safari 浏览器安装方法（推荐用户脚本）

1. 在 Mac App Store 免费下载 **[Userscripts](https://apps.apple.com/app/userscripts/id1463298887)**（开源无广告，亦可使用 Tampermonkey / Stay）；
2. 打开 Safari 设置 -> 扩展，启用 Userscripts；
3. 点击 Safari 工具栏的 Userscripts 图标，点击右上角 `+` 新建脚本；
4. 复制本项目中的 **`j-split.user.js`** 完整代码，粘贴覆盖并按 `Command + S` 保存；
5. 打开 **[https://syosetu.com/?ref=ncodeheader](https://syosetu.com/?ref=ncodeheader)**，进入任意小说章节：
   - 看到右下角的 `[ 🌸 意群助读 ] [ ⚙️ ]`；
   - 点击 **⚙️ 齿轮**，填入你的 API Key，点击「🔄 自动检索模型」并保存；
   - 点击 **🌸 意群助读**（或按快捷键 `Alt + S`），随手点击任意虚线短语即可享受极简沉浸翻译！

## 💻 Chrome / Edge 扩展安装方法

1. 打开 Chrome / Edge，访问 `chrome://extensions/`；
2. 开启右上角 **「开发者模式」**；
3. 点击左上角 **「加载已解压的扩展程序」**，选择本项目文件夹；
4. 点击扩展栏图标 🌸 填入 API Key 并保存；
5. 访问 **[https://syosetu.com/?ref=ncodeheader](https://syosetu.com/?ref=ncodeheader)** 小说页面体验。
